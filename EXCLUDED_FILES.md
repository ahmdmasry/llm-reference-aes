# Files intentionally excluded

The following materials were excluded from the public package:

- ASAP and OS dataset files;
- feature files containing full student-response text;
- full-response prediction/error-review workbooks;
- duplicate task-specific pipeline scripts;
- complete exported LLM chat transcripts;
- manuscript drafts, screenshots, and temporary notebook files;
- superseded analyses and duplicate figures.

Public-safe numerical feature copies were generated by removing response-text
columns. The redacted error-case file contains no student responses or reviewer
notes that quote them.
