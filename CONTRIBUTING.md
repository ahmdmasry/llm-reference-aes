# Contributing

This repository is primarily an archival research artifact. Corrections that
improve reproducibility without changing the reported experimental design are
welcome.

Before submitting a contribution:

1. Do not add raw ASAP or OS student responses.
2. Do not add credentials, private paths, exported account data, or personal
   identifiers.
3. Keep generated outputs outside version control unless they are required to
   document a reported result.
4. Run `python -m compileall -q code`.
5. Explain whether the change affects numerical reproducibility.

For material changes to scoring, preprocessing, splitting, or model settings,
open an issue before preparing a pull request.
